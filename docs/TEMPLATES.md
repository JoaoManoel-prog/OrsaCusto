# Templates Alternativos

Este diretório contém templates alternativos para diferentes tipos de aplicação.
Após a definição dos requisitos, o template apropriado será movido para a raiz do projeto.

## Opções Disponíveis:

### 1. Python Desktop (Tkinter)
- Interface gráfica nativa
- Sem necessidade de servidor
- Banco de dados local

### 2. Web Application (Flask/FastAPI)
- Interface web moderna
- API RESTful
- Frontend separado

### 3. Web Full Stack (Django)
- Framework completo
- Admin panel integrado
- ORM robusto

### 4. JavaScript/Node.js
- Frontend com React/Vue
- Backend com Express
- MongoDB ou PostgreSQL

Aguardando definição do usuário para prosseguir com o template apropriado.
