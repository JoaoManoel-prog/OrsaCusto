# Guia de Contribuição - OrsaCusto

## Bem-vindo!

Obrigado pelo interesse em contribuir com o projeto OrsaCusto!

## Como Contribuir

### 1. Estrutura do Projeto

O projeto será organizado de forma modular para facilitar manutenção e expansão.

### 2. Padrões de Código

- Código limpo e bem documentado
- Comentários em português para facilitar o entendimento
- Nomes de variáveis descritivos

### 3. Commits

Use mensagens de commit claras e descritivas:
- `feat:` para novas funcionalidades
- `fix:` para correções de bugs
- `docs:` para documentação
- `style:` para formatação
- `refactor:` para refatoração de código
- `test:` para testes

### 4. Testes

- Sempre teste suas alterações antes de commitar
- Adicione testes para novas funcionalidades

## Dúvidas?

Abra uma issue para discussão!
